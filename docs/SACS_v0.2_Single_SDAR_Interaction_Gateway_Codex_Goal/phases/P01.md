# P01 — 双协议合同与 ADR 冻结

## 实施

- ADR：dual northbound / single interaction core。
- 冻结 `/ag-ui` HTTP/SSE、auth、content negotiation。
- 使用 exact official AG-UI types 编译 RunAgentInput/Event/Interrupt/Resume。
- 冻结 A2A→Interaction→AG-UI mapping。
- 冻结 Run != Task、Tool/Raw 边界。
- 新增 architecture/source contract tests。

## 阶段门禁

- official AG-UI types decide wire
- no second A2A adapter

## GitHub 交付

阶段结束必须：

```text
implementation/evidence complete
→ git diff --check
→ phase commit(s)
→ push
→ verify local HEAD == remote feature HEAD
→ update reports/v0.2/goal-state.json
```

至少一个可识别 `p01` 的阶段提交。大型阶段优先 implementation + evidence 两个提交，
但不能为了形式拆碎无意义提交。

## 必需报告

reports/v0.2/p01-completion.md
