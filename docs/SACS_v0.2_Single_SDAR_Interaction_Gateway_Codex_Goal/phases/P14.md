# P14 — Final Main Sync / PR / Protected Merge

## 实施

- merge latest origin/main into feature，禁止 rebase。
- 重跑所有真实 E2E/release gates。
- final release evidence commit+push。
- create/update PR。
- 等待 required review/checks。
- Merge Commit if allowed。
- 证明 final candidate ancestor of origin/main。
- post-merge smoke/consistency。

## 阶段门禁

- no protection bypass
- no tag/release/deploy

## GitHub 交付

阶段结束必须：

```text
implementation/evidence complete
→ git diff --check
→ phase commit(s)
→ push
→ verify local HEAD == remote feature HEAD
→ update reports/v0.2/goal-state.json
```

至少一个可识别 `p14` 的阶段提交。大型阶段优先 implementation + evidence 两个提交，
但不能为了形式拆碎无意义提交。

## 必需报告

```text
reports/v0.2/p14-completion.md
reports/v0.2/p14-acceptance.json
reports/v0.2/p14-publication.md
```

失败 required 尝试追加到 `reports/v0.2/failed-attempts/`，不得删除或重标 PASS。
