# P05 — AG-UI HTTP/SSE Endpoint

## 实施

- 实现 `POST /ag-ui`、`GET /ag-ui/capabilities`。
- Fastify route + official RunAgentInput validation。
- 使用 official Event/Encoder SSE。
- 实现 AG-UI service auth/principal mapping。
- Abort 只终止当前观察。
- 最小 Run/Text/Finish/Error vertical slice。

## 阶段门禁

- official client fixture consumes
- malformed input fail closed

## GitHub 交付

阶段结束必须：

```text
implementation/evidence complete
→ git diff --check
→ phase commit(s)
→ push
→ verify local HEAD == remote feature HEAD
→ update reports/v0.2/goal-state.json
```

至少一个可识别 `p05` 的阶段提交。大型阶段优先 implementation + evidence 两个提交，
但不能为了形式拆碎无意义提交。
