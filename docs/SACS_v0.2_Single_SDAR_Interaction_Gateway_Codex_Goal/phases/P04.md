# P04 — Query Service 与 Task Authorization

## 实施

- 实现 capability/active/status/result/history/conversation/previous/allowed-actions/capability-gap queries。
- Capability 来源 current Agent Card。
- Task current facts 来源 authorized binding + A2A getTask。
- 查询意图 deterministically 优先于 task submission。
- Agent Card LKG 只作为 safe degraded query cache。

## 阶段门禁

- unbound taskId rejected
- query creates no task
