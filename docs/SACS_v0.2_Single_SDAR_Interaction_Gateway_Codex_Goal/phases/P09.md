# P09 — Security / Privacy / Rate / CORS

## 实施

- 统一 Principal security policy。
- 独立 service credentials + JWT validation。
- request/event/data size limits。
- redaction/logging policy。
- CORS allowlist、rate limit。
- URL part/SSRF policy。
- Raw/Tool leak prevention。
- 完整 adversarial suite。

## 阶段门禁

- security matrix all pass
- secret scan

## GitHub 交付

阶段结束必须：

```text
implementation/evidence complete
→ git diff --check
→ phase commit(s)
→ push
→ verify local HEAD == remote feature HEAD
→ update reports/v0.2/goal-state.json
```

至少一个可识别 `p09` 的阶段提交。大型阶段优先 implementation + evidence 两个提交，
但不能为了形式拆碎无意义提交。

## 必需报告

```text
reports/v0.2/p09-completion.md
reports/v0.2/p09-acceptance.json
reports/v0.2/p09-publication.md
```

失败 required 尝试追加到 `reports/v0.2/failed-attempts/`，不得删除或重标 PASS。
