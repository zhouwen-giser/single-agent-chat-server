# P08 — Run 幂等、断线、恢复、长任务

## 实施

- durable run/request claim。
- same id+hash replay，same id+different hash conflict。
- crash before/after A2A submission recovery。
- disconnect only aborts observation。
- bounded stream→poll。
- later run query from binding。
- PostgreSQL restart rebuild。

## 阶段门禁

- no duplicate Task
- disconnect does not cancel

## GitHub 交付

阶段结束必须：

```text
implementation/evidence complete
→ git diff --check
→ phase commit(s)
→ push
→ verify local HEAD == remote feature HEAD
→ update reports/v0.2/goal-state.json
```

至少一个可识别 `p08` 的阶段提交。大型阶段优先 implementation + evidence 两个提交，
但不能为了形式拆碎无意义提交。

## 必需报告

```text
reports/v0.2/p08-completion.md
reports/v0.2/p08-acceptance.json
reports/v0.2/p08-publication.md
```

失败 required 尝试追加到 `reports/v0.2/failed-attempts/`，不得删除或重标 PASS。
