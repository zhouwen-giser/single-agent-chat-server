# P11 — Official AG-UI Client Real E2E

## 实施

- 使用 exact pinned official `@ag-ui/client` HTTP agent/client。
- 真实 POST/SSE against built SACS。
- Run/Text/State/Activity/Custom。
- Interrupt/Resume。
- abort/reconnect/run idempotency。
- client schema/type verification。

## 阶段门禁

- not curl-only
- official client real E2E

## GitHub 交付

阶段结束必须：

```text
implementation/evidence complete
→ git diff --check
→ phase commit(s)
→ push
→ verify local HEAD == remote feature HEAD
→ update reports/v0.2/goal-state.json
```

至少一个可识别 `p11` 的阶段提交。大型阶段优先 implementation + evidence 两个提交，
但不能为了形式拆碎无意义提交。

## 必需报告

```text
reports/v0.2/p11-completion.md
reports/v0.2/p11-acceptance.json
reports/v0.2/p11-publication.md
```

失败 required 尝试追加到 `reports/v0.2/failed-attempts/`，不得删除或重标 PASS。
