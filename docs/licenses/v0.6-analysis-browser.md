# Browser reference client dependencies

The reference client pins `@noble/hashes@2.0.1` (MIT) for browser SHA-256 checks, `esbuild@0.25.11` (MIT, development only) for the browser bundle and `playwright-core@1.56.1` (Apache-2.0, development only) for actual Chromium verification. Official package metadata records Node requirements >=20.19.0, >=18 and >=18 respectively, compatible with the project's pinned Node 22.14.0 container. Browser installation is a test preparation step, not a production dependency.

The existing canonical JSON/Snapshot checks are reused through a browser-only crypto alias; server crypto is unchanged. Only UTF-8 byte counting is injected for the existing client's Buffer calls. Cross-runtime tests cover ASCII, Chinese, emoji, combining characters and unpaired surrogates. The build manifest records inputs and rejects server/test/Node builtin boundaries.

Official references: [esbuild API](https://esbuild.github.io/api/), [noble-hashes source and license](https://github.com/paulmillr/noble-hashes), and [Playwright browser installation](https://playwright.dev/docs/browsers). Exact package integrity is recorded in `pnpm-lock.yaml`; semantic comparison confirms no pre-existing package resolution/integrity was changed. The project license remains Apache-2.0.
