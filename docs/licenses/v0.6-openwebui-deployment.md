# Independent Open WebUI deployment

The optional Docker frontend uses the unmodified official Open WebUI
`v0.11.3-slim` image, pinned on this machine to
`ghcr.io/open-webui/open-webui@sha256:bb3633af77b35d97783affc9cd8097d8a6dc89fedd5a410ce9a50d85556a870c`.
Its OCI revision is `2a960a59fe1dbbd35282f0556b3666d81102e781`.

Open WebUI uses the upstream Open WebUI License, including its branding
condition; earlier materials retain the licenses described in LICENSE_HISTORY.
The deployment retains the official name, branding and image content. This
frontend is an independent service, outside the SACS production npm dependency
inventory. The SACS project remains Apache-2.0, and its dependency lock is
unchanged.
