# Frozen consumer runtime dependencies

The frozen public validator uses pinned `ajv@8.20.0` and `ajv-formats@3.0.1`, both MIT licensed. Ajv was already a direct SACS dependency; ajv-formats already existed in the lock graph and is now explicitly direct. No unrelated versions are upgraded.

Their locked transitive MIT dependencies are `fast-deep-equal@3.1.3`, `fast-uri@3.1.6`, `json-schema-traverse@1.0.0` and `require-from-string@2.0.2`. The standalone upstream verification bundle's vendored node_modules remains outside SACS. SACS consumes only the original public contract files and resolves validator dependencies through its own pnpm lock.

WSGS public source provenance and exact artifact hashes: `reports/v0.6/frozen-wsgs-consumer/SOURCE_IMPORT.json`. Importing this contract does not change SACS's Apache-2.0 project license or assert real upstream qualification.
