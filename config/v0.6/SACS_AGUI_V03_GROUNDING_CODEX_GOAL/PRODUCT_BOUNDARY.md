# Product Boundary

SACS owns: interaction contract, durable Analysis binding, safe WSGS result normalization, AG-UI v0.3 projection, Analysis Control validation, reference/headless client behavior and tests.

WSGS owns: Grounding semantics, world/reference resolution, provider orchestration, authoritative Findings/evidence/geometry/currentness.

Frontend owns: rendering, viewport, hover, local selection, local layer visibility, draft geometry editing and explicit user confirmation.

SACS must never invent WSGS internals or convert a local UI gesture into an implicit analysis mutation.
