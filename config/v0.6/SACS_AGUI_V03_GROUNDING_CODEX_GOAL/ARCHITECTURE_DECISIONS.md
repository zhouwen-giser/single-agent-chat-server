# Architecture Decisions
- ADR-01: reuse AG-UI v0.3 event families; no Grounding CUSTOM stream.
- ADR-02: `grounding.job` Activity is distinct from `analysis.dag`.
- ADR-03: map navigation/inspection terminates locally.
- ADR-04: geometry editing requires explicit commit.
- ADR-05: FocusTarget + stable IDs form cross-view navigation authority.
- ADR-06: full Snapshot is synchronization/reconnect authority.
- ADR-07: Grounding requery creates new Revision/Grounding; Native compileRevision remains deferred.
- ADR-08: TOOL_CALL requires real authoritative tool lifecycle.
