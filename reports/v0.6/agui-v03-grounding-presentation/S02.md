## Implementation and authority

- The frozen view has a bounded `linkage` index for findings, features, timeline items, choices, evidence and source products. Feature navigation uses the existing strict FocusTarget contract; a single-layer geometry has an explicit feature identity in this index without modifying upstream geometry bytes.
- Joins require published IDs plus their type and owning Finding. In particular, a road visit and an off-network segment with identical ID text cannot borrow each other's geometry. Event choices retain their public event ID; reference choices retain the exact public reference key.
- Spatial preview identity uses public featureId, not array position. Time-only rows without upstream IDs use the parent Finding, semantic role/kind and canonical published period record. These display IDs do not authorize geometry or backend selection.
- Off-network preview samples without individual public IDs form one segment-scoped MultiPoint layer. Sample coordinates remain exact; no line or gap interpolation is created. Independently published LineString previews remain independent.
- Payload trimming rebuilds navigation against retained objects. Duplicate unqualified identities and unavailable associations are omitted rather than inferred. Raw Findings, exact choice selectors and all historical execution restrictions remain unchanged.
