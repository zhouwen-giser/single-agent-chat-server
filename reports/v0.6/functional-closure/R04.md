# R04 显式浏览器交互与观察恢复

R04 完成 FC-14–FC-17。候选检查、地图绘制和导航保持本地；明确的确认、重查或取消按钮才调用既有 Analysis Control。命令成功后观察同一 Analysis，只有经过 hash/身份校验的权威 Snapshot 更新当前 Revision。

## 行为

候选确认复用 HeadlessAnalysisReferenceClient 的当前 Revision/intervention/selector/TTL 检查，服务端再读取完整持久化 Source 验证。过期候选仍可读，确认禁用；显式重查不复制过期 selector。界面当前 Activity 只显示当前 Revision。

点、线、闭合面和 Circle 可从地图手势或严格 JSON 输入建立本地草稿。预览显示精确几何、hash、草稿 generation 和 CONTINUE/REPLACE；编辑/重绘/清除使旧确认失效。Circle 原样传输，页面仅标记中心，不用近似 Polygon 替代空间语义。Source 未实际支持的行为不能据本地 fixture 判为真实空间查询通过。

控制处理中禁用按钮；双击不会产生第二次提交。显式同键重放保留确切 command bytes/key，不自动重试。更换用户或 Analysis 清除局部控制与旧 replay，并核对重放目标仍属于当前 Analysis。最后视图在断开/有界观察结束时保留；重连请求完整 State/Activity，不重复 START。

取消先显示提交中，权威持久化 Snapshot 显示 CANCEL_REQUESTED；仅公开 source CANCELLED 更新最终状态。来源仍运行时，AG-UI 观察窗口结束可继续恢复观察，不把窗口结束当作业务完成。

## 验证

业务起点 `62baac2`，稳定源清单、命令、退出码及截图摘要见 [R04-validation.json](R04-validation.json)。**12/12** 浏览器/身份回归、**4/4** 实际 Chromium + TCP/SSE + 隔离 PostgreSQL 控制场景，以及 **79/79** 受影响 client、entry 与 focus-link 回归通过；typecheck、架构、build、scoped lint 均 exit 0。lint 有 non-null assertion warnings，没有 errors。

- FC-14：检查计数为零提交，显式确认仅携带完整公开 selector；同一 Analysis 生成一个新 Revision，双击及同键 replay 均无第三个 Job。
- FC-15：地图点绘制/清除不发请求；旧 review 被禁用。Point、LineString、Polygon、Circle 的确切 geometry/hash 进入正式公开 request；CONTINUE/REPLACE 的 priorGroundings 数量分别为 1/0，readOnly=true、allowApproximation=false。
- FC-16：客户端/服务器时钟超过候选 TTL 后仍可阅读、不能确认。测试在服务端提交成功后丢掉客户端响应，旧视图保持；显式同键重放的两个 body 完全一致，数据库只有一个逻辑新工作。
- FC-17：断开不 cancel，重连不 START。取消 fixture 保持公开 RUNNING，页面显示 CANCEL_REQUESTED；释放公开终态后才显示 CANCELLED，并核对实际 PostgreSQL cancel_requested 与 last_source_status。

[范围界面截图](R04-browser/scope.png) 已视觉检查，数据与身份均为本地测试材料。普通回归截图默认写 `.tmp`；阶段验证使用专有目录，R03 历史图片及 receipts 保持原字节。

首次 PostgreSQL fixture 使用了小于生产允许下限的 recovery interval，四项初始化均失败；之后使用允许的 1000 毫秒，并增加 setup-failure 清理。失去引用的测试进程按已知专有 PID 终止，临时容器已清理；不能把该次失败计为通过。初始测试误用了未公开的 pool 属性及不存在的 PENDING view status，已修正为独立测试查询 pool 和正式 RUNNING 状态。最终 launcher 每次先构建当前 bundle，避免旧产物替代当前源码。

本阶段固定 180 秒 production lease 不变；浏览器 fixture 的 1 秒 recovery tick 不代表生产进程恢复资格。真实 SIGKILL、数据库中断与多进程竞争在 R05 验证。没有调用真实 WSGS、模型、SDAR、Provider 或设备。
