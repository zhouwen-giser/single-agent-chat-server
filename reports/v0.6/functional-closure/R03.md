# R03 同源认证浏览器世界分析展示

R03 交付 `/analysis` 浏览器参考客户端，对应 FC-10–FC-13。页面复用现有 HeadlessAnalysisReferenceClient、MapEngineAdapter、AG-UI v0.3 Grounding handler 和 Analysis Control；Open WebUI 源码及冻结 WSGS/A2A 合同没有修改。

## 实现与边界

入口默认关闭，启用时必须配置精确 HTTP(S) public origin 并使用 authenticated 身份模式。既有可信 `open-webui` 签名 JWT 换取 HttpOnly/SameSite=Strict 会话，HTTPS 下 Secure，最多 300 秒且不超过 JWT expiry；每次请求重验身份。POST 同时核对 Origin 和会话 CSRF。服务密钥只由后端注入到固定本机 loopback 端口，桥接路径只限 Analysis 和 AG-UI，无任意 URL/请求头转发。

目录通过 PostgreSQL principal subject/role 与 AG-UI thread binding 联合授权，最多返回 100 项。当前浏览器目录限定 AG-UI 绑定，不把 OpenAI Chat 的内部 thread 重映射为另一个客户端。跨用户读取返回 404；退出/换用户清理查询、分析标识、目录和检查详情，旧响应受身份/observer generation 隔离。

页面提供目录、Revision、Source Activity、最终文字、公开几何、时间轴、Finding、证据、来源产品、候选和历史行动要求。来源 geometry 独立绘制，Gap 保持断开；仅本地平移/缩放/fit/图层开关/检查。SVG 使用相对展示原点避免近距离单点的浮点精度损失，原始经纬度和共享状态不变。未知表示、无几何和 payload reference 不触发远程读取。文本节点与同源 CSP 限制 HTML/外部资源注入。

页面独立 build 与正常 build/Dockerfile 均包含 bundle。Node crypto 只在 browser build 中别名到 pinned noble-hashes，UTF-8 字节计数使用 TextEncoder；服务器 crypto 和 hash 逻辑保持原值。依赖 pin/许可见 [浏览器依赖](../../../docs/licenses/v0.6-analysis-browser.md)，运行设置见 [浏览器指南](../../../docs/deployment/analysis-browser.md)。
